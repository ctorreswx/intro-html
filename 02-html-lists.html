About HTML lists 🤔

HTML lists are used to group related items together in a structured format. There are three main types of lists in HTML: ordered lists, unordered lists, and definition lists. As one of the most important and simple things in HTML, they appear frequently in web pages.

Types of HTML Lists

Unordered Lists (UL)

An unordered list is a collection of items that do not have a specific order or sequence. Each item in the list is typically represented by a bullet point. Unordered lists are created using the <ul> element, and each item within the list is represented by the <li> element.

  • Item 1
  • Item 2
  • Item 3

Ordered Lists (OL)

An ordered list is a collection of items that have a specific order or sequence. Each item in the list is typically represented by a number or letter. Ordered lists are created using the <ol> element, and each item within the list is represented by the <li> element.

  1. First item
  2. Second item
  3. Third item

Note: The type of numbering for an ordered list can be customized using the type attribute on the <ol> element. For example:

  1. First item
  2. Second item
  3. Third item

And if you want it to start at a different number, you can use the start attribute:

  1. First item
  2. Second item
  3. Third item

Definition Lists (DL)

A definition list is a collection of terms and their corresponding definitions. Definition lists are created using the <dl> element, and each term-definition pair is represented by the <dt> and <dd> elements.

Nested Lists

HTML lists can also be nested, meaning that one list can be placed inside another list. This allows for the creation of more complex and hierarchical structures. Nested lists can be created by placing a new <ul>, <ol> or <dl> element inside an existing <li> element.
